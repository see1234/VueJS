# VueJS Homework Collection

Collection of Vue.js and frontend homework projects stored in one repository.

## Preview
![VueJS layout preview](VueJSHW-1/layout/image/Header_Photo.jpg)
![VueJS blog preview](VueJSHW-2/layout/image/banner_top.jpg)

## Structure
- `VueJSHW-1` to `VueJSHW-3`: static HTML/CSS/JS tasks and layouts
- `VueJSHW-4` to `VueJSHW-8`: Vue CLI/Vue projects with separate `layout` and, in some cases, `task` apps

## How To Run
For plain HTML tasks, open the corresponding `index.html` file in a browser.

For Vue-based tasks:
```bash
cd VueJSHW-4/layout
npm install
npm run serve
```

Replace the path with any other Vue homework folder as needed.
